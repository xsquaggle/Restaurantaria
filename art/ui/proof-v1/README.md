# Pizzeria UI proof package v1

Prepared October 18, 2026. Working visual direction; Lawson has not yet confirmed the shift feel or style.

Start with **Review.html** to view all 11 selected transparent images on checker, white or dark backgrounds. This is an image gallery, not a gameplay prototype.

## Contents

- **Style-guide-v1.md** — concrete visual, typography, mobile, animation and production rules, with official Roblox references.
- **Asset-briefs.md** — use, reference size, states, transparency, source windows, candidate nine-slice settings and acceptance criteria for each requested asset category.
- **assets/** — blank ticket, four-tab backplate, four primary button states, oven-ring shell, and four patience expressions/empty tracks.
- **asset-manifest.json** — measured dimensions, alpha bounds, selected filenames, hashes, candidate integration metadata and contrast measurements.
- **QA-report.md** — checks performed and limitations. Read before calling these production-ready.
- **Generation-prompts.json** — exact built-in image-generation prompts and refinements.
- **Message-to-Claude.txt** — copy-ready review and next implementation request.

The selected idle and highlighted button files include **v2** in their names because contrast checks prompted a darker face. Their earlier versions are excluded from this package.

These are high-resolution source proofs, not optimized runtime textures or a packed atlas. Live functional text, progress fills, timer arcs and hit regions must be built in Studio. No Studio upload or actual-phone validation occurred in this task.

The agreed prototype still requires **12 progressively unlocked pizza-related recipes**. The smaller First Shift build remains an internal milestone.
