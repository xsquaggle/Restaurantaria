ORIGIN AND FILES
Visible artwork originates in native image generation. Code was used only for technical cropping, resizing, alignment, alpha preparation, packaging and QA previews. Runtime text remains live. All runtime images are RGBA PNGs no larger than 1024px on their longest side. The intentionally opaque generated scrim is dimmed at runtime; other assets carry transparency.

The root manifest is normalized for import. metadata/ holds original family manifests and QA records for provenance; their original relative paths refer to the family working folders, so import from the root manifest instead. prompts/ retains generation instructions and reference lineage. References to original local generation paths in provenance are historical, not required runtime dependencies.
